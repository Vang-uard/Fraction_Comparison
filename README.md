# GSAT 반복 숙달 🧠

GSAT(삼성직무적성검사) 대비를 위한 반복 연습 웹앱입니다.

## ✅ 구현된 기능

### 1. 알파벳 외우기
- 알파벳 순서(위치) 암기 연습
- 난이도 3단계: 하 / 중 / 상
  - 하: 알파벳 → 순서 번호 맞추기
  - 중: 알파벳 ± 숫자 연산
  - 상: 변환 패턴 추론
- 오답 시 팁 이미지/텍스트 표시 (`alpha_tips/` 폴더)

### 2. 분수 비교 연습
- 두 분수 중 큰 값 클릭 방식
- 난이도 3단계: 하(퍼센트 비교) / 중 / 상
- 정답률 실시간 트래킹 (프로그레스 바)
- `localStorage`에 점수 저장/불러오기
- 점수 초기화 버튼

### 3. 곱셈 연습
- 두 수의 곱셈 문제 자동 생성
- 첫 번째/두 번째 수 범위 설정 가능
- Enter 키로 정답 제출, 자동 다음 문제 진행

### 4. 도식 추리
- 증감변환 / 순서변환 두 가지 유형
- 난이도 2단계: 하(규칙 찾기) / 상(새 코드에 규칙 적용)
- Enter 키 또는 채점 버튼으로 제출

## 📱 모바일 대응

- **768px 이하**: 햄버거 메뉴 + 서랍형 사이드바
- **오버레이 클릭**으로 사이드바 닫기
- 모든 입력 요소 터치 친화적 크기
- 400px 소형 모바일까지 대응

## 🗂️ 파일 구조

```
index.html          — 메인 HTML (전면 재디자인)
style.css           — 스타일시트 (CSS 변수 기반 디자인 시스템)
script.js           — 전체 기능 로직 (변경 없음)
alpha_tips/         — 알파벳 팁 이미지 폴더 (K.png, L.png 등)
README.md           — 이 파일
```
